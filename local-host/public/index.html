Tự động đồng bộ IP WAN mạng nhà lên DuckDNS để truy cập từ xa qua tên miền cố định khi ra ngoài.

HƯỚNG DẪN NAT PORT CHO ESP32 Cấu hình trên modem Wi-Fi (mục Virtual Server / Port Forwarding) để truy cập ESP32 từ 4G hoặc mạng ngoài:
Cách 1: Mở thẳng cổng 80 (Chuẩn Web, không cần gõ port): Port ngoài: 80 ➜ IP ESP32: 192.168.1.5:80 (ALL) Truy cập: http://<domain>.duckdns.org (Nếu 4G vào được bình thường)
Cách 2: Cổng ngoài 8080 (Dự phòng nếu mạng 4G chặn port 80): Port ngoài: 8080 ➜ IP ESP32: 192.168.1.5:80 (ALL) Truy cập: http://<domain>.duckdns.org:8080 (Dùng nút mở nhanh bên dưới tự gán)
